# Product Requirements Authority

This directory owns durable product requirements for user-facing capabilities.
It is not a roadmap, delivery status board, deployment record, or runtime
evidence source.

Each product area has one indexed requirement set. Architecture decisions,
wire protocols, executable operations, and runtime acceptance remain in their
existing owning documentation domains.

## Indexed products

- [`external-knowledge/`](external-knowledge/README.md) defines the product
  contract for connecting governed Agent Apps to an enterprise-managed external
  knowledge service, beginning with the company's existing RAGFlow deployment.
